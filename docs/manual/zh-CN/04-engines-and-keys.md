# 04 引擎与 API Key

[English](../en/04-engines-and-keys.md)

Totype 有三个识别引擎：本地 SenseVoice 离线运行、不需要 Key；Soniox 和阿里云百炼是云端引擎，需要你自己的 API Key，并按量向服务商付费。默认主引擎是本地。想要实时识别、说完立刻出结果，选云端引擎。

## 三个引擎

| 引擎 | 联网 | Key | 特点 |
|---|---|---|---|
| 本地（SenseVoiceSmall q8） | 不需要 | 不需要 | 结束录音后才一次性出结果，没有实时字幕。只支持 Apple 芯片。不使用个人词库和说话人背景 |
| Soniox（stt-rt-v5） | 需要 | 需要 | 实时识别；支持术语表、说话人背景和提示词 |
| 阿里云百炼（千问实时语音） | 需要 | 需要 | 实时识别；支持热词和提示词；北京或新加坡区域 |

在历史窗口的“设置”页，“识别”一节的“主模型”选择器可以在“本地”“阿里云”“Soniox”之间切换。

![设置页的识别一节](../../images/settings-engines.png)

## 申请和保存 Key

在“设置”页的“云端密钥”一节：

1. **Soniox。** 到 Soniox 控制台（`https://console.soniox.com`）注册并创建 API Key，粘贴到 Soniox 一栏的“API Key”输入框，点“保存”。保存后旁边显示“已配置”。
2. **阿里云百炼。** 点“获取 Key”打开阿里云的说明页，按页面步骤在百炼控制台创建 Key。先在“阿里云区域”里选择与 Key 所属站点一致的区域：“华北2（北京）”对应中国站，“新加坡”对应国际站。把 Key 粘贴到阿里云百炼一栏并保存，再点“测试阿里云连接”验证。

输入框留空再点“保存”会删除对应的 Key。Key 的存放位置见 [07 数据与隐私](07-data-and-privacy.md)。

## 费用

云端引擎按用量计费，费用由服务商直接向你收取，Totype 不经手也不收费。价格和免费额度请以各服务商的价格页为准，价格会变动。使用前建议先在服务商控制台设置额度上限或余额提醒。

保留录音与历史的话，你可以用“重新转写”对同一段音频换一个云端引擎再跑一次，这同样会产生一次云端用量。

## 两个云端同时配置：主用和热备

两个云端的 Key 都保存后，你选的主引擎负责这次录音，另一个云端同时在后台作为热备，两个引擎都会收到你的音频。主引擎出错、余额不足或收尾太慢时，Totype 会采用热备的结果，浮窗注明改用了哪一个。热备还有一个用途：两个引擎的结果可以互相佐证，用于误听别名的恢复，见 [05 个性化](05-personalization.md)。

当某个云端因余额不足或 Key 被拒绝而不可用时，菜单面板顶部会显示例如“Soniox 余额不足，已改用阿里云”，并给出“去充值”（或“检查 Key”）和“重试”两个动作。充值或更正 Key 后点“重试”。

## 云端失败时会发生什么

Totype 绝不静默降级到 macOS 系统听写。云端失败时有两种去向，都会让你看见：

- 设置里的“云端异常时自动使用本地模型”默认开启。云端没有及时给出结果时，Totype 用保留的音频在本地转写，浮窗上标出“本地”。想让云端失败时直接报错，可以关掉这个开关，音频仍保留在历史里，之后可以重新转写。
- 本地模型没有安装完整时，这个后备不可用。

“保留 Apple 对照”（在“高级与诊断”里）默认关闭。打开后，系统听写的结果只作为历史里的对照，从不用于插入。

## 安全建议

- 给云端 Key 设置额度上限，并只在自己的电脑上使用。
- 不要把 `personal-secrets.json` 或包含它的备份发给别人。
- 在不再使用某个云端时，清空它的 Key 并点“保存”。
