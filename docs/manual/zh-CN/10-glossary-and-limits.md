# 10 名词与限制

[English](../en/10-glossary-and-limits.md)

## 名词表

| 名词 | 含义 |
|---|---|
| 主引擎 | 设置里选定的识别引擎，负责这次录音 |
| 热备 | 两个云端都配置时，另一个云端在后台同时识别，主引擎失败或过慢时采用它的结果 |
| 本地后备 | 云端没有及时给出结果时，用保留的音频在本地转写；设置里的“云端异常时自动使用本地模型”控制它 |
| 定稿 | 引擎给出这次录音的最终文字 |
| 浮窗 | 屏幕底部显示录音状态的胶囊提示 |
| 预览卡片 | 无法确认插入位置时，显示文字并让你选择插入或复制的卡片 |
| 个人词库 | 你登记的词与误听别名，以及自动学习到的词 |
| 别名 | 引擎常把某个词听成的错误写法 |
| 恢复 | 有另一个引擎佐证时，把别名换回正确写法，是唯一的文字改动 |
| 重新转写 | 用历史里保留的音频再识别一次，结果追加为新版本 |
| 辅助功能 | macOS 权限，用于向其他应用的输入框发送文字 |
| 输入监控 | macOS 权限，用于监听右 Option 和 Esc |
| Secure Input | macOS 在密码输入等场景下独占键盘事件的机制，期间全局热键可能无效 |
| 公证（notarization） | Apple 对分发应用的安全检查；Totype 的预编译版本未经公证 |

## 已知限制

- 仅支持 Apple 芯片和 macOS 15 及以上版本。
- 本地引擎只在结束录音后一次性给出结果，没有实时字幕；不使用个人词库、说话人背景和提示词，对夹杂的英文术语不如云端。
- 误听别名的恢复需要同时配置 Soniox 和阿里云两个 Key，只用本地模式时不生效。
- 应用界面目前只有简体中文。
- 应用未经 Apple 公证，第一次打开需要手动放行，更新后三项权限可能需要重新授权。
- Electron 应用、自绘界面和部分网页编辑器不暴露输入框内容，Totype 无法确认插入结果，历史里记为“已发送”。
- 单次录音默认最长 180 秒。
- 历史窗口只显示最近 20 条，更早的记录仍在数据目录里。
- 聊天类应用的判断依据是应用标识的固定列表，浏览器统一按聊天类处理。
- GitHub Releases 上的预编译 dmg 即将提供；在此之前请从源码构建（`VERBATIM_BUNDLE_MODEL=0` 得到精简版）。
