# 08 故障排查

[English](../en/08-troubleshooting.md)

大多数问题出在三个地方：权限没有生效、云端 Key 或余额有问题、目标应用不接受插入。先看菜单面板，它会直接写出当前的问题和下一步。

## 按右 Option 没有反应

1. 菜单面板顶部有没有“Esc 取消不可用：需要重新授权输入监控”。有的话，输入监控授权已失效，按 [02 首次运行与授权](02-first-run.md) 删除旧条目、重新授权、重启应用。
2. 状态里有没有“Secure Input 正在开启”。密码框或某些应用会让系统独占键盘事件，退出密码框或关闭占用它的应用。
3. 应用是否在运行：菜单栏有没有它的图标。
4. 右 Option 是否被其他软件占用（键盘映射或其他语音输入工具）。

## Esc 不能取消

通常是输入监控授权丢失。浮窗和菜单面板会显示“Esc 不可用”。重新授权并重启应用。

## 文字没有插入，只出现预览卡片

预览卡片表示 Totype 无法确认该把文字放在哪里，见 [03 日常使用](03-daily-use.md)。点“插入当前输入框”或“复制”。如果总是出现，检查菜单面板“插入”一栏是否为“辅助功能 · 可用”，不是就重新授权辅助功能。

## 更新后授权丢失

未公证的构建在更新后代码签名会变化，三项授权可能失效。删掉 Totype 在麦克风、辅助功能、输入监控里的旧条目，重新授权，再重启应用。从源码构建的用户用稳定的本机签名身份可以避免。

## 云端提示

| 提示 | 含义与处理 |
|---|---|
| “已选择 Soniox，但未配置 API Key；不会切换到系统听写” | 主引擎是 Soniox，但没有保存 Key。到设置保存 Key，或改用本地 |
| “Soniox 余额不足，已改用阿里云” | Soniox 账户余额不足，这次由热备完成。点菜单面板的“去充值”，充值后点“重试” |
| 带“检查 Key”按钮的提示 | 服务商拒绝了 Key。核对 Key、区域是否匹配，重新保存 |
| “云端较慢，已改用本地”“云端不可用，已改用本地” | 云端没有及时给出结果，用保留的音频在本地转写 |
| “主云不可用，已采用热备结果” | 主引擎出错，已采用另一个云端的结果 |
| “没有得到可用的转写结果” | 所有可用引擎都没有返回文字，错误详情附在后面；音频仍在历史里，可以稍后重新转写 |

阿里云连接问题，先点设置里的“测试阿里云连接”，它会显示“连接成功：区域”或具体失败原因。区域选错是常见原因。

## 本地模型相关

“本地 SenseVoice 模型不完整”表示模型文件缺失或损坏。从源码构建的用户重新运行 `scripts/install.sh`；精简版到 设置 → 识别，用“本地模型”一行的“下载”或“重试”按钮重新下载；选了本地引擎但模型缺失时，应用也会提示这条路径。菜单面板“主引擎”后出现“未配置”也是这个原因。

## 识别结果不理想

- 云端引擎配上术语表和说话人背景通常有帮助，见 [05 个性化](05-personalization.md)。
- 本地引擎只在结束后出结果，没有实时字幕，对夹杂的英文术语不如云端稳定。
- 在历史里用“重新转写”换另一个引擎对比。

## 收集诊断信息

提交问题时，请提供：macOS 版本、芯片型号、应用版本、所用引擎、三项权限的状态，以及出问题那次录音在历史“详情”里的主引擎、热备、插入方式和时间线几行。不需要贴转写原文，也不要贴 API Key。需要更详细的材料时，仓库里的 `tools/history_report.py` 可以从 `history.jsonl` 生成统计，贴出前请先看一遍内容。
