# 00 概览

[English](../en/00-overview.md) · [目录](#目录)

Totype 是 macOS 菜单栏里的语音输入法。它接一流的识别模型：云端用 Soniox 和阿里云百炼的实时识别，说完几乎立刻出结果；也可以完全离线，用本地的 SenseVoice。按一下右 Option 开始说话，再按一下，文字就插入到当前输入框。默认情况下，插入的就是引擎听到的文字，不用大模型润色；改多少由你决定。使用它需要 Apple 芯片的 Mac 和 macOS 15 或更高版本。

## 它做什么

Totype 把你说的话变成文字，放进光标所在的位置，中间改多少由你决定。默认设置很严格，下面几条在任何设置下都成立：

- 不用大模型改写你的文字。默认情况下，识别结果里的重复、口头语、自我修正和中英文夹杂都原样保留。想让结果更整齐，可以调转写提示词、术语表、别名和插入偏好，见 [05 个性化](05-personalization.md) 和 [06 改多少](06-literal-rules.md)。
- 一次说话最多插入一次。即使插入过程中出现不确定，也不会重复插入同一段文字。
- 音频先落盘。录音在识别完成之前就已经写入磁盘，识别失败或被取消后仍可从历史里重新转写。
- 唯一的文字改动，是恢复一个你登记过的已知误听：当两个云端引擎对同一个位置给出不同结果，而另一个引擎听到的正是你登记的正确写法时，才会替换。细节见 [05 个性化](05-personalization.md)。

它从不静默地改用 macOS 系统听写。选定的引擎不可用时，界面会明确告诉你原因，以及这次实际由哪个引擎完成。

## 适合谁

经常用中文口述、夹杂英文术语，并且想自己掌握“改我多少”的人，比如写文档、写提示词、在聊天软件和终端里输入长句的用户。Totype 没有总结、翻译或大模型润色的模式。

## 系统要求

- Apple 芯片的 Mac（M1 及以后），macOS 15 或更高版本。
- 使用本地引擎需要约 250 MB 磁盘空间存放模型，不需要账号和网络。
- 使用云端引擎需要自己的 Soniox 或阿里云百炼 API Key，并按量向服务商付费。

## 界面语言

应用界面目前只有简体中文。英文说明书引用界面文字时，会保留中文原文并在括号里给出英文解释。

## 术语约定

本说明书把菜单栏图标点开的小面板称为“菜单面板”，屏幕底部的胶囊状提示称为“浮窗”，从菜单面板里的“打开历史…”进入的窗口称为“历史窗口”，它左侧有历史列表，右侧是详情，也包含“设置”和“个人资料”两个页面。
